## Result

Repository classified as a **frontend-only Angular 14 SPA/PWA**. It has remote authentication, profile, and navigation API integrations, but no backend, SSR, admin, database, serializers, migrations, email, or printable-view code in this repository.

### Main changes

- Integrated `@neetechs/ui` styles globally without changing version `0.0.3`.
- Migrated the app shell, header, navigation, buttons, menus, avatars, profile menu, notification center, cards, badges, panels, alerts, skeletons, loading, empty, and error states.
- Added responsive layouts, logical RTL properties, accessible labels, focus behavior, reduced fake content, and localized document `lang`/`dir`.
- Replaced hard-coded user identities and stock-photo notifications with authenticated profile data and a truthful empty state.
- Added backend-cookie/system theme bootstrap without creating app-owned appearance settings.
- Registered the production service worker and corrected invalid web manifest/Firebase JSON.
- Preserved `/`, `/home`, historical wildcard deep-link behavior, and added `/404`.
- Corrected the invalid production build script.

### Authentication and API changes

- Credential `postMessage` handling now validates both the Accounts origin and iframe source.
- JWT interceptor now attaches the existing token only to backend requests.
- Existing 401/403 logout behavior and account redirects remain.
- Locale headers are now registered globally.
- Profile requests use typed DTOs and URL-safe usernames.
- Remote navigation responses are typed and expose loading, retry, error, empty, and content states.
- No backend code or API compatibility was changed because none exists locally.
